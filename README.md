# Парсер цен с сайта в Excel (Python)

Демонстрационный скрипт для сбора данных с сайта (книжный магазин).

Функции: Сбор названий, цен, рейтинга и наличия товаров. Очистка данных от лишних символов. Сохранение в Excel (xlsx). Обработка ошибок и паузы между запросами.
Стек: Python, requests, BeautifulSoup, pandas.

Как запустить:

Установите зависимости: pip install -r requirements.txt
Запустите: python parser.py
Результат появится в файле books_parsed.xlsx

Скрипт можно адаптировать под любой сайт. Сложные сайты с защитой (Avito, Ozon и т.д.) требуют использования Selenium/Playwright и прокси.
